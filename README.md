# Sách Điện Tử Văn Học: Muối Của Rừng — Nhóm 3

Ấn bản sách điện tử lật trang **22 trang** (khổ `5:8` chuẩn xuất bản, chạy mượt cả khi mở trực tiếp `file://` lẫn trên **GitHub Pages**) phục vụ bài học Ngữ văn 12: **"Muối của rừng"** (Nguyễn Huy Thiệp, 1986).

## Đặc điểm Phiên bản 4
- **Trải nghiệm sách văn học thuần khiết:** Trang giấy dó kem không khung hộp rườm rà, chữ có chân `Lora` thụt đầu dòng kinh điển kết hợp chữ Drop-cap đầu chương và 4 trang tranh minh họa toàn khổ đan xen đối xứng.
- **Nội dung sâu sắc, chuẩn xác 100% nguyên tác (22 trang):** Trình bày đầy đủ từ *Lời mở đầu, Hồ sơ tác phẩm, Sơ đồ mạch truyện 5 chặng, 5 Chương phân tích hành trình đi săn của ông Diểu* cho tới *Hệ thống biểu tượng & Dư âm thi pháp*.
- **Giọng đọc theo từng chương & tự động lật trang:** Ngay dưới tiêu đề mỗi chương đều có nút **Nghe đọc...** tối giản; tự động đọc trọn vẹn các trang thuộc chương đó, tô sáng nhẹ đoạn đang đọc và tự lật trang sang trang kế tiếp, kèm thanh điều khiển mini gọn ngoài lề dưới.

## Cách gắn file giọng đọc của Nhóm 3

1. Bấm nút **Giọng đọc** trên thanh công cụ góc phải để nghe hoặc gắn thử file ghi âm cho từng chương.
2. Trước khi đẩy lên GitHub Pages, đặt các file thu âm (`.mp3` / `.m4a`) vào thư mục `audio/` theo tên gợi ý trong [audio/README.md](./audio/README.md) (ví dụ `audio/tom-tat.mp3`, `audio/chuong-1.mp3` ... `audio/chuong-5.mp3`).

## Cách đăng lên GitHub Pages lấy link gửi nhóm lớp

1. Tạo repository **Public** trên GitHub và đẩy dự án lên nhánh `main` *(5 ảnh gốc dung lượng lớn đã được tự động loại trừ qua `.gitignore`, toàn bộ bản nén đưa lên web chỉ nặng ~1.16 MB)*.
2. **Để Zalo/Messenger hiện ảnh bìa khi gửi link:** Mở `index.html`, thay `content="./assets/images/og-cover.jpg"` ở thẻ `og:image` và `twitter:image` thành link tuyệt đối `https://<ten-tai-khoan>.github.io/<ten-repo>/assets/images/og-cover.jpg`.
3. Vào **Settings → Pages → Source: Deploy from a branch**, chọn **`main`** / **`/(root)`**, bấm **Save** và gửi link cho thầy cô cùng nhóm lớp!
