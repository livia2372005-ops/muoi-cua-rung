# Sách Điện Tử Minh Họa: Muối Của Rừng — Nhóm 3

Ấn bản sách điện tử lật trang 16 trang (khổ `5:8` chuẩn xuất bản, chạy mượt cả khi mở trực tiếp `file://` lẫn trên **GitHub Pages**) phục vụ bài học Ngữ văn 12: **"Muối của rừng"** (Nguyễn Huy Thiệp, 1986).

## Điểm nổi bật (Phiên bản 3)
- **Hệ mỹ thuật đồng bộ với 5 tranh minh họa gốc:** Tông màu rừng thông trầm, đá vôi đất nung, sương mù Hõm Chết và giấy dó kem `Lora` cổ điển.
- **Lật trang cong chân thực (`StPageFlip`):** Kéo góc trang bằng chuột hoặc ngón tay, tự động căn giữa bìa đầu/bìa cuối trên máy tính và điều hướng gọn nhẹ ở chân trang trên điện thoại.
- **Bản đồ Đường mòn 5 Chặng & Giọng đọc đồng bộ (Trang 4–5):** 5 trạm minh họa nối theo quan hệ nhân quả cùng sóng âm Ink-Wave và phụ đề đồng bộ thời gian thực.
- **La bàn Chuyển hóa 5 bước tương tác (Trang 12):** Trực quan hóa đối cực *Bị tước bỏ / Tự nguyện trút bỏ vật chất* vs *Sự thức tỉnh thiên lương*.
- **Tối ưu chia sẻ Zalo / Messenger:** Ảnh preview `assets/images/og-cover.jpg` (`1200×630`) và toàn bộ tranh nén nhẹ chỉ **~1.1 MB**.

## Cách gắn file giọng đọc của Nhóm 3

1. Bấm nút **Giọng đọc** trên thanh công cụ để xem và sao chép kịch bản 5 chặng (kèm gợi ý ngữ điệu đọc).
2. Thu âm xuất file `.mp3` (hoặc `.m4a`):
   - **Nghe thử ngay trên máy:** bấm **Chọn file thu âm phát thử** bên trong hộp thoại **Giọng đọc**.
   - **Gắn cố định lên GitHub Pages:** đặt tên là **`tom-tat.mp3`** và chép vào thư mục `audio/` (`audio/tom-tat.mp3`).

## Cách đăng lên GitHub Pages lấy link gửi nhóm lớp

1. Tạo repository **Public** trên GitHub (ví dụ `muoi-cua-rung-nhom-3`) và đẩy toàn bộ dự án lên nhánh `main` *(5 file ảnh gốc 2K kích thước lớn đã được liệt kê trong `.gitignore` để trang tải nhanh cho cả lớp trên 4G)*.
2. **Mẹo hiện ảnh bìa đẹp trên Zalo/Messenger:** Mở `index.html`, thay `content="./assets/images/og-cover.jpg"` ở thẻ `og:image` và `twitter:image` thành link tuyệt đối `https://<ten-tai-khoan>.github.io/<ten-repo>/assets/images/og-cover.jpg`.
3. Vào **Settings → Pages → Source: Deploy from a branch**, chọn **`main`** / **`/(root)`**, bấm **Save** và lấy link gửi lên nhóm lớp!
