# Hướng dẫn gắn file thu âm từng chương (Nhóm 3)

Website hỗ trợ **8 đoạn giọng đọc độc lập** cho từng phần/chương của sách. Khi chưa có file thu âm, bấm nút **"Nghe đọc..."** ở đầu mỗi chương sẽ tự động đọc trọn vẹn các trang của chương đó và tự lật trang theo tiến độ.

Để gắn giọng tự đọc thật của **Nhóm 3** trước khi đẩy lên GitHub Pages, hãy chép file `.mp3` (hoặc `.m4a`) tương ứng vào thư mục `audio/` này theo đúng tên:

- `audio/loi-mo-dau.mp3` — Lời mở đầu (Trang 2)
- `audio/tom-tat.mp3` — Sơ đồ tóm tắt 5 chặng (Trang 4–5)
- `audio/chuong-1.mp3` — Chương I: Tâm thế kẻ chinh phục (Trang 7–8)
- `audio/chuong-2.mp3` — Chương II: Tiếng hú nơi bờ vực Hõm Chết (Trang 10–11)
- `audio/chuong-3.mp3` — Chương III: Cỏ Lào, Núi lở & Phóng sinh (Trang 13–15)
- `audio/chuong-4.mp3` — Chương IV: Sắc trắng hoa tử huyền (Trang 16)
- `audio/chuong-5.mp3` — Chương V: Tước bỏ để tái sinh (Trang 18–19)
- `audio/ket-luan.mp3` — Hệ thống biểu tượng & Dư âm thi pháp (Trang 20–21)

Bạn cũng có thể mở mục **Giọng đọc** trên thanh công cụ để gắn thử nhanh file ghi âm trên máy tính/điện thoại ngay trong trình duyệt.
