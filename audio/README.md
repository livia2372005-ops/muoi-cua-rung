# Hướng dẫn gắn file giọng đọc (Nhóm 3)

Để trang sách điện tử tự động phát bản thu âm giọng đọc của **Nhóm 3** khi mở web trên GitHub Pages:

1. Thu âm phần tóm tắt theo **Kịch bản tự đọc** (có sẵn nút xem & sao chép ngay trên trang web).
2. Đặt tên file là **`tom-tat.mp3`** (hoặc `.m4a`, `.wav`, `.ogg`) và chép trực tiếp vào thư mục **`audio/`** này:
   - `audio/tom-tat.mp3` *(khuyên dùng để tương thích tốt nhất mọi trình duyệt và điện thoại)*
3. Bạn cũng có thể bấm nút **"Gắn thử file ghi âm"** ngay trên thanh phát âm thanh của web để nghe thử và kiểm tra độ khớp với sơ đồ 5 chặng trước khi chép vào thư mục này và đẩy lên GitHub.
